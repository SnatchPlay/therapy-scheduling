# Дельта: app-access

## Purpose

Що бачить користувач, який не увійшов або увійшов без ролі: сторінку входу чи повідомлення про відсутність доступу,
без жодних даних практики.

## ADDED Requirements

### Requirement: Без входу видно лише сторінку входу

IF користувач не увійшов у застосунок, THEN the system SHALL показати йому лише сторінку входу, не показувати даних клієнтів чи утримань і не змінювати жодної картки.

#### Scenario: AC-CARD-07 Спроба відкрити дані без входу

- **GIVEN** користувач не увійшов у застосунок
- **WHEN** він відкриває за прямим посиланням список клієнтів, картку client6 або список утримань
- **THEN** він бачить лише сторінку входу
- **AND** жодних даних клієнтів чи утримань не показано
- **AND** жодна картка не змінилася

### Requirement: Без ролі видно лише повідомлення про відсутність доступу

IF користувач увійшов, але не має ролі, THEN the system SHALL показати йому лише повідомлення «Your account has no access yet. Contact an administrator.», не показувати даних клієнтів і не змінювати жодної картки.

#### Scenario: AC-CARD-11 Користувач без ролі

- **GIVEN** користувач newuser1@example.test увійшов, але не має ролі
- **WHEN** він відкриває застосунок або картку client6 за прямим посиланням
- **THEN** він бачить лише повідомлення «Your account has no access yet. Contact an administrator.»
- **AND** жодних даних клієнтів не показано
- **AND** жодна картка не змінилася
